Personalisierte Tracking-Links erzeugen

Empfängerliste einfügen → fertige Links, fertige Nachrichten und die Versandliste fürs Dashboard.
Ohne personalisierten Link ist im Dashboard nur „irgendwer war da“ sichtbar — mit Link steht der Name dran.

Was hier wirklich getrackt wird: Nicht der Klick innerhalb von WhatsApp — den gibt WhatsApp nicht heraus — sondern das Öffnen der Seite direkt danach. Praktisch dasselbe, nur eine Sekunde später. Die WhatsApp-Linkvorschau führt kein JavaScript aus und erzeugt deshalb keinen Fake-Klick.

1 · Kampagne konfigurieren

Die Seite, auf der der Empfänger landen soll.
Wird als ?src= angehängt.
Wird als ?msg= angehängt — zeigt, welche Nachricht den Klick ausgelöst hat.
Schlüssel für den Nicht-Klicker-Abgleich. Pro Versand eindeutig.

2 · Empfänger einfügen

Erste Zeile = Spaltenüberschriften. Erkannt werden: name/vorname, telefon/handy, email/mail, lead_id/id/c_id. Trennzeichen (;, ,, Tab) wird automatisch erkannt.
Platzhalter: {{vorname}}, {{name}}, {{link}}, {{msg}}.

4 · Versandliste ans Dashboard senden

Erst dadurch kann das Dashboard zeigen, wer nicht geklickt hat. Ohne diesen Schritt sieht es nur die, die kommen.

Leer lassen, wenn diese Seite schon auf dem Deployment liegt.
Dasselbe wie im Dashboard-Login. Wird nicht gespeichert.
Datenschutz: In den Links steht keine Telefonnummer und keine E-Mail — Empfänger ohne CRM-ID bekommen eine aus ihren Kontaktdaten berechnete Kurz-ID (gleiche Person = gleiche ID, aus der ID lässt sich die Nummer nicht zurückrechnen). Der Vorname ist optional abschaltbar.
